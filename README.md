# Wi-Fi Inventory Audit

Аудит Wi-Fi-точек по инвентаризационному CSV: непрерывно сканирует эфир, сверяет точки
с инвентарным списком **по BSSID** и проверяет пароль из CSV реальным подключением
к конкретной точке. Результат — таблица с цветовыми статусами и файлы в папке `results`.

## Возможности

- непрерывный скан до нажатия «Стоп» (интервал настраивается);
- сопоставление по BSSID (MAC точки), а не по имени сети;
- проверка пароля: временный WLAN-профиль → подключение именно к этому BSSID → отключение;
  в системе профиль не сохраняется;
- цвета: зелёный — наличие и пароль подтверждены, жёлтый — только наличие, красный — пароль
  не подошёл, серый — точка не найдена, синий — 802.1X/открытая сеть (пароль не проверяется);
- отдельные колонки «Проверка пароля» и «Статус»: видно, подтверждено только наличие или ещё и пароль;
- авто-перечитывание CSV при изменении файла;
- журнал событий, фильтр «только подтверждённые / проблемы», скрытие паролей в таблице;
- отдельная вкладка **«Поиск сетей»** — разовый скан или непрерывный мониторинг
  (при двух адаптерах — на отдельном радио);
- вкладка **«Найденные»** — накопленная за сеанс история найденных точек (зелёные/красные);
- всё сохраняется в папку **`results`**: полный результат, история найденных, история поиска;
- экспорт поиска в CSV и копирование значения любой ячейки по клику (в обеих таблицах);
- экспорт только подтверждённых строк: **Файл → Экспорт подтверждённых…**.

## Требования

- Windows 10/11, Python 3.10+ (проверено на 3.13), только стандартная библиотека;
- Wi-Fi адаптер;
- для получения списка сетей Windows требует разрешение на определение местоположения:
  **Параметры → Конфиденциальность и защита → Местоположение** → включить службы
  и «Разрешить классическим приложениям доступ к точному расположению».
  Альтернатива — запуск от имени администратора;
- **проверка паролей отключает адаптер от текущей сети** на время каждой попытки.
  Для аудита лучше использовать Ethernet или отдельный USB Wi-Fi адаптер.

## Запуск

```bat
python app.py
```

или двойной клик по `run.bat`. Демо без реального Wi-Fi:

```bat
python app.py --demo
```

Полезные параметры: `--csv путь.csv`, `--interval 2`, `--no-verify` (только наличие),
`--interface 0`, `--monitor-interface 1`, `--output wifi_result.csv`, `--checks-per-cycle 5`
(сколько паролей проверять за один цикл; 0 — все ожидающие).

Кнопки: **▶ Запуск** / F5, **■ Стоп** / Esc.

## Поиск сетей

Вкладка **«Поиск сетей»** → кнопка **«Сканировать»**. Делает разовый скан и показывает
все видимые BSSID: SSID, BSSID, время первого обнаружения, RSSI (0–100) и dBm, канал,
частоту, диапазон, тип защиты, стандарт 802.11, максимальную скорость, Beacon, тип BSS
и флаги возможностей.
Сканирование пассивное: профили не создаются, подключения не выполняются.
Кнопку можно нажимать и во время аудита: скан встаёт в очередь и выполняется в паузе
между проверками паролей (используется тот же адаптер), поэтому возможна задержка
«Ожидание Wi-Fi адаптера…».

- **«Экспорт…»** сохраняет текущую таблицу в CSV (UTF-8 BOM, разделитель `;`).
- **«▶ Мониторинг»** — непрерывный скан с заданным интервалом: таблица постоянно
  показывает, какие точки сейчас в эфире; у каждой точки видно время первого обнаружения;
  новые BSSID дописываются в `scan_found.csv` вместе с этим временем.
  Повторное нажатие («■ Стоп») останавливает.
- **Клик по любой ячейке** копирует её значение в буфер обмена (подтверждение — справа
  в строке состояния вкладки). Так же работает клик по ячейкам таблицы инвентаризации.
- В демо-режиме показывает вымышленные `CORP-*`.

## Инвентаризация и мониторинг одновременно

Аудит (вкладка «Инвентаризация») и мониторинг (вкладка «Поиск сетей») можно держать
включёнными одновременно:

- аудит сканирует эфир, сверяет BSSID с CSV и проверяет пароли;
- мониторинг в это же время повторяет сканы и обновляет таблицу видимых сетей;
- результаты не смешиваются: аудит пишет `results/wifi_result.csv` и
  `results/audit_found.csv`, мониторинг — `results/scan_found.csv`;
- если нужно только следить за наличием точек без проверки паролей, выключите
  «Проверять пароли» или запустите с `--no-verify` — тогда оба режима работают быстро.

### Два Wi-Fi адаптера

Если в системе два Wi-Fi адаптера, приложение автоматически берёт **первый для аудита,
второй для мониторинга**. В строке состояния видны оба адаптера.

- мониторинг работает независимо и не ждёт проверки паролей;
- аудит сканирует и проверяет пароли на своём адаптере;
- каждый адаптер видит эфир по-своему (антенна, диапазон, расположение), поэтому
  список в «Поиске сетей» может отличаться от того, что видит аудит;
- можно задать вручную: `--interface 0 --monitor-interface 1`
  (или наоборот, если адаптеры называются иначе);
- если у USB-адаптера выключен software radio, приложение включает его автоматически
  при запуске (аппаратный переключатель на корпусе оно не трогает).

С одним адаптером режимы работают последовательно: проверка пароля имеет приоритет,
мониторинг ждёт паузы и показывает «ожидание Wi-Fi адаптера…».

Вкладка **«Найденные»** — история за текущий запуск: все точки, которые аудит когда-либо
увидел в эфире, по одной строке на BSSID. Зелёные — наличие и пароль подтверждены,
красные — пароль не подтверждён, жёлтые — проверка ещё идёт, синие — открытая/802.1X.
Файл `results/audit_found.csv` обновляется сразу при появлении точки; повторно одна и та же
точка не добавляется, при смене статуса строка обновляется на месте.

## Формат CSV

Файл — обычный CSV (не переименованный XLSX). Подходит и такой формат:

```csv
time;bssid;sec;essid;key;city;address;;;;
14.08.2020;aa:bb:cc:dd:ee:ff;WPA/WPA2;WiFi-test-01;testPassword;test city;test adress;;;
```

Лишние пустые колонки в конце (`;;;;`) игнорируются.

- разделитель `;`, `,`, табуляция или `|` — определяется автоматически;
- кодировка UTF-8, UTF-8 BOM или cp1251; одиночные `\r` (старые выгрузки) тоже читаются;
- обязательна колонка **BSSID**; понимаются заголовки `BSSID`, `MAC`, `MAC-адрес`,
  `Физический адрес` и т. п.;
- колонки `SSID`/`ESSID`/`Имя сети` и `Пароль`/`Password`/`PSK`/`Key`/`Ключ`
  распознаются по заголовку;
- лишние колонки сохраняются как есть и попадают в результат;
- BSSID можно писать `AA:BB:CC:DD:EE:FF`, `AA-BB-...`, `aabbccddeeff`;
- пароль берётся из строки без обрезки пробелов;
- пустой пароль = «только наличие»; для открытых сетей пароль не нужен.

Образцы: `wifi.example.csv` (корпоративная схема) и `wifi.synthetic.csv`
(та же структура, что `time;bssid;sec;essid;key;city;address`, но с вымышленными
сетями `CORP-*` — используется в `run_demo.bat`).

## Статусы

| Цвет | Статус | Значение |
|---|---|---|
| зелёный | наличие и пароль подтверждены | BSSID виден, подключение с паролем из CSV прошло |
| жёлтый | только наличие | BSSID виден, пароль ещё не проверен / проверяется |
| красный | пароль не подошёл | подключение не удалось |
| серый | не найдена | BSSID не виден в эфире |
| синий | 802.1X / открытая | пароль не проверяется (нужны учётные данные 802.1X либо пароль не требуется) |

Строки в таблице и в экспорте упорядочены так: подтверждённые (зелёные) — сверху,
затем найденные без проверки пароля, затем с неверным паролем, в конце не найденные.
Новая подтверждённая строка автоматически прокручивается в видимую область.

## Результаты

Все файлы создаются в подпапке **`results`** рядом с приложением (`app.py`),
в одном месте независимо от того, откуда открыт инвентаризационный CSV
(папка создаётся автоматически):

- `wifi_result.csv` — полная текущая таблица: исходные колонки плюс `Наличие`,
  `Проверка пароля`, `Статус`, `RSSI`, `Обнаружена`, `Последний раз`, `Примечание`,
  `Проверено`; успешная авторизация сверху, неуспешная снизу; перезаписывается атомарно;
- `audit_found.csv` — найденные аудитом точки за сеанс, по одной строке на BSSID,
  обновляется сразу; при запуске приложения создаётся заново;
- `scan_found.csv` — новые точки, найденные кнопкой «Сканировать», по одной строке
  на BSSID, со временем первого обнаружения; создаётся заново при запуске.

Файлы содержат пароли — обращайтесь с ними соответственно.
Экспорт из меню (**Файл → Экспорт результата…**, **Экспорт только подтверждённых…**)
по умолчанию предлагает папку `results`.
Если BSSID в CSV не найден, но в эфире есть точка с тем же SSID и BSSID, отличающимся
на один символ, в «Примечании» будет подсказка — частая опечатка в инвентаре.

## Ограничения и скорость

- WPA2-PSK проверяется только реальным подключением: 2–12 с на точку, физически быстрее
  нельзя. Сканирование Presence-режима — 2–5 с на цикл.
- Результат проверки кэшируется: повторно точка не проверяется, пока не нажмёте
  «Сбросить проверки» или не изменится пароль в CSV.
- 802.1X (WPA-Enterprise) паролем из CSV не проверяется — только наличие.
- WPA3-SAE поддерживается, если драйвер и Windows 11 умеют `WPA3SAE`; иначе будет
  «пароль не подошёл» с примечанием.
- Скрытые сети не поддерживаются.
- Если несколько BSSID используют один SSID, подключение ограничивается целевым BSSID;
  при невозможности зафиксировать BSSID статус будет «не подтверждён» с примечанием.

## Если что-то не работает

- «Нет доступа к файлу» — CSV открыт в Excel; закройте файл.
- «это XLSX, а не CSV» — сохраните книгу как «CSV UTF-8 (разделитель — запятая)».
- «Сети не видны» — включите определение местоположения, проверьте антенну/адаптер,
  попробуйте запуск от администратора.
- «Пароль не подошёл», хотя он верный — сеть 802.1X (проверка паролем невозможна),
  WPA3-драйвер не поддерживает `WPA3SAE`, либо адаптер подключился к другому BSSID
  (смотрите «Примечание»).
- Во время проверки паролей Wi-Fi отключается — это ожидаемо, см. выше.
